# Deep_learning
1.Project: Breast Cancer Classification using ANN
2.Dataset: Breast Cancer Wisconsin dataset
3.Tech: Python, NumPy, Pandas, Scikit-learn, PyTorch
4.Preprocessing: Train/test split + StandardScaler
5.Model: 30 → 40 → 30 → 1 ANN
6.Loss: Binary Cross Entropy
7.Optimizer: Adam
8.Result: ~97.37% test accuracy
